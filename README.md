# Cadence

Cadence is an appointment scheduling application designed to give clients useful booking choices while helping practitioners avoid gaps in their working day. It accounts for different appointment lengths and cleanup time when deciding which times to offer.

The planned booking experience brings together appointment management, returning client profiles, intake forms, saved payment methods, and email and text reminders. Clients should be able to book, reschedule, and cancel in one place, with clear confirmation at each step.

Cadence is under development; appointment booking is not yet available.
